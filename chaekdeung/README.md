# 책등

책을 읽다가 마음에 남은 한 줄을 남기면, 같은 시간에 쉬는 낯선 독자에게 불빛으로 도착하는 조용한 독서 서비스입니다.

## 구조

| 경로 | 역할 |
|---|---|
| `public/index.html` | 화면 전체 (한 파일). 서버가 없으면 시뮬레이션 데모로 동작합니다. |
| `public/admin.html` | 관리자 화면 (`/admin.html`). 비밀번호가 있어야 데이터를 볼 수 있습니다. |
| `public/sounds/` | 녹음된 소리 파일과 출처(`CREDITS.md`) |
| `src/worker.js` | Cloudflare Worker. `/api/*`, `/go`, 정적 파일을 한 주소에서 제공합니다. |
| `schema.sql` | D1(SQLite) 테이블 정의 |
| `test/books.test.mjs` | 도서 검색 응답 정리, 입력 필터, 기본 문장 테스트 |

## 화면 기능

- **풍경:** 지금 시각(낮 6시~저녁 6시)과 계절에 맞춰 바뀝니다. 설정에서 낮·밤, 계절을 직접 고를 수도 있어요.
  봄은 벚꽃, 여름은 반딧불(밤)과 햇빛 알갱이(낮), 가을은 단풍, 겨울은 눈이 내립니다.
- **분위기용 불빛:** 서버가 연결되어 있어도 불빛은 항상 10개 이상 떠 있습니다 (`public/index.html`의 `MIN_LAMPS`).
  화면의 숫자 문구("지금 N명이 함께 읽고 있어요")는 실제 접속자 수만 말하고, 0명이면 "고요한 밤이에요"라고만 합니다.
- **소리:** 녹음된 자연의 소리와 피아노. 상단 "소리"에서 한 번 누르면 바로 재생되고, 기본은 꺼짐입니다.
  지난번에 켜 둔 소리는 다음 방문에서 "읽기 시작"을 누를 때 이어서 켜집니다. 출처와 라이선스는 `public/sounds/CREDITS.md`.
- **고마워요(♡):** 받은 문장 카드에서 누르면 글 없이 마음만 전해집니다. 한 사람이 한 문장에 한 번만 셉니다.
  보낸 사람은 다음에 접속할 때 "♡ 고마워요가 N개 도착했어요"를 보고, 서랍의 "내 밑줄"에서 개수를 봅니다.
- **서랍:**
  - 담은 문장의 책: 서점 링크(알라딘, 교보문고, 예스24). "빼기"로 목록에서 뺄 수 있어요.
  - 받은 문장: 담은 문장. "지우기"로 지웁니다.
  - 내 밑줄: 내가 남긴 문장 (책과 좋았던 문장만 보관). "지우기"를 누르면 서버에서도 거둬들입니다.
    이미 다른 사람의 서랍에 담긴 복사본은 지울 수 없어요.
  - 지우기와 빼기는 한 번 더 눌러야 실행됩니다.

### 문장이 전달되는 방식
1. 독자 A가 문장을 보내면 서버에 쌓입니다. (A가 접속해 있지 않아도 됩니다.)
2. 독자 B의 읽기 시간이 끝나는 순간 서버가 문장 하나를 골라 B에게 줍니다.
   - 1순위: 아직 많이 전달되지 않은 **독자의 문장** (한 문장은 최대 3명에게)
   - 2순위: 아직 안 본 **책등이 고른 문장** (관리자가 넣은 문장)
   - 3순위: 책등이 고른 문장을 다시 보여 줍니다.
3. 자기 문장, 이미 받은 문장, 신고 2회 이상 쌓인 문장은 제외됩니다.
4. 서버가 없는 데모에서는 화면에 내장된 예시 문장 8개가 나옵니다.

### 개인정보와 남용 방지
- 로그인이 없습니다. 브라우저가 만든 무작위 기기 ID만 씁니다.
- IP는 해시로만 보관하고, 하루 사용 횟수 제한에만 씁니다. (보내기 기기당 3회, IP당 12회 등)
- 문장 1줄은 100자, 받는 분께 한 줄은 40자까지. 링크와 연락처 패턴은 서버에서도 막습니다.
- 받은 문장만 신고할 수 있고, 받은 문장에만 고마워요를 보낼 수 있습니다.
- 서점 링크 클릭은 서점과 책 이름만 세고, 누가 눌렀는지는 저장하지 않습니다.

## 로컬에서 실행

```bash
npm install
npm run db:init:local
npm run dev
```

http://localhost:8787 에서 열립니다. 브라우저 두 개(또는 시크릿 창)로 열어 한쪽에서 문장을 보내고 다른 쪽에서 읽기를 끝내 보세요.

관리자 화면을 로컬에서 쓰려면 `.dev.vars` 파일(git에 올라가지 않아요)을 만들고 비밀번호를 적습니다.

```
ADMIN_TOKEN=아무_비밀번호
```

그 뒤 http://localhost:8787/admin.html 로 들어갑니다. "책등이 고른 문장" 탭에서 **기본 10개 넣기**를 누르면 독자에게 돌아다닐 문장이 준비됩니다.

스키마가 바뀐 뒤에는 로컬 DB를 새로 만들어야 합니다 (`.wrangler/state` 폴더를 지우고 `npm run db:init:local`).

테스트:

```bash
npm test
```

## 지금 배포된 서비스

- 주소: https://chaekdeung.chaekdeung.workers.dev (관리자: `/admin.html`)
- 이 배포는 정적 파일(화면, 소리)을 KV에 넣는 방식(`wrangler.kv.toml`)으로 올렸습니다.
  화면이나 소리를 고친 뒤 다시 올리려면:

```bash
python3 scripts/kv_bulk.py kv-bulk.json
```

```bash
npx wrangler kv bulk put kv-bulk.json --namespace-id=672fafb335be41b68b15bcd25c1d7d4e --remote
```

```bash
npx wrangler deploy -c wrangler.kv.toml
```

- 아래의 "배포 (Cloudflare)"는 `wrangler.toml`의 `[assets]`를 쓰는 기본 방식입니다. 둘 중 하나만 쓰면 돼요.

## 배포 (Cloudflare)

```bash
npx wrangler login
npx wrangler d1 create chaekdeung
```

출력된 `database_id`를 `wrangler.toml`에 넣고:

```bash
npm run db:init
npx wrangler secret put KAKAO_REST_API_KEY
npx wrangler secret put ADMIN_TOKEN
npx wrangler secret put IP_SALT
npm run deploy
```

배포한 뒤 `/admin.html`에서 "책등이 고른 문장 → 기본 10개 넣기"를 한 번 눌러 주세요.

| 이름 | 용도 |
|---|---|
| `KAKAO_REST_API_KEY` | 도서 검색(책을 고를 때 자동 검색). [Kakao Developers](https://developers.kakao.com)에서 앱을 만들고 REST API 키를 씁니다. 서버가 `dapi.kakao.com`을 대신 호출하므로 이 주소를 따로 등록할 필요는 없어요. |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | (선택) 카카오가 실패할 때 쓰는 두 번째 검색. 네이버가 개발자 센터에서 NAVER API HUB로 옮겨 가는 중이라 새로 발급받는 키의 호출 방식이 코드와 다를 수 있어요. |
| `ADMIN_TOKEN` | 관리자 화면 비밀번호. 길고 무작위인 문자열로. |
| `IP_SALT` | IP 해시에 섞는 무작위 문자열 |
| `AFFILIATE_ALADIN`, `AFFILIATE_KYOBO`, `AFFILIATE_YES24`, `AFFILIATE_COUPANG` | (선택) 제휴 링크 주소. 아래 설명 참고 |

키가 하나도 없으면 도서 검색은 Google Books, 그것도 안 되면 샘플 목록으로 대체됩니다.
각 API의 이용약관(출처 표기, 하루 호출 한도)은 배포 전에 확인하세요.

## 서점 제휴 수익

서랍의 "담은 문장의 책"에서 서점 버튼을 누르면 `/go`가 클릭을 센 뒤 서점으로 보냅니다.
기본값은 각 서점의 검색 주소(수익 없음)이고, 제휴 프로그램에서 받은 링크로 바꾸려면 환경 변수에 `{q}` 자리를 넣은 주소를 넣습니다.

```bash
npx wrangler secret put AFFILIATE_COUPANG
# 입력 예: https://파트너_링크_주소...{q}
```

- `{q}`는 책 제목과 첫 저자가 주소용으로 바뀐 값으로 대체됩니다.
- `AFFILIATE_COUPANG`을 넣으면 쿠팡 버튼이 자동으로 나타납니다.
- 제휴 프로그램마다 링크 형식과 표시 의무(대가를 받는다는 안내)가 다릅니다. **제휴 링크를 실제로 켜기 전에 각 프로그램의 약관과 표시 규정을 확인하세요.**
  지금 화면에는 제휴 안내 문구가 없습니다.

## 관리자 화면

`/admin.html`에서 비밀번호(`ADMIN_TOKEN`)로 들어갑니다.

- 지금 읽는 사람, 오늘 보낸 문장, 신고 대기, ♡ 합계 같은 숫자
- 신고된 문장 / 숨긴 문장 / 독자 문장 목록과 숨기기, 복원, 삭제 (삭제는 두 번 눌러야 해요)
- **책등이 고른 문장:** 책, 저자, 문장, 한 줄을 직접 추가·수정·삭제합니다. 독자가 아직 많지 않을 때 이 문장들이 돌아다녀요.
  저작권이 만료된 작품이나 직접 쓴 글을, 책 한 권에서 한 줄만 옮기세요.
- 서점별, 책별 클릭 수

비밀번호를 20번 틀리면 그날은 그 IP에서 잠깁니다.
