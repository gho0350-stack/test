# 소리 출처

책등의 소리는 위키미디어 커먼즈에 공개된 녹음을 가져와 다듬은 것입니다.
받은 날(2026-11-20) 커먼즈에 표시된 라이선스는 아래와 같고, 모두 출처 표기 의무가 없는 퍼블릭 도메인 또는 CC0입니다.
그래도 서비스를 공개하기 전에 각 파일 페이지에서 라이선스 표시가 그대로인지 한 번 더 확인해 주세요.

## 다듬은 내용
- 한 채널(모노)로 바꾸고, 구간을 잘라 음량을 같은 크기로 맞췄습니다.
- 바람, 비, 시냇물, 풍경은 끝과 처음이 자연스럽게 이어지도록 겹쳐 붙여 반복 재생해도 끊기지 않게 만들었습니다.
- 피아노는 시작에 1.5초, 끝에 6초의 페이드를 넣었습니다.
- 모두 MP3로 다시 저장했습니다.

## 소리를 바꾸거나 더하려면
1. 파일을 이 폴더에 넣습니다. (바람·빗소리·시냇물·풍경은 30~80초 정도, 반복해도 이음새가 들리지 않는 것)
2. `public/index.html`의 `SOUNDS` 목록에 `{ id, label, desc, file }`을 추가합니다.
3. 이 표에 출처와 라이선스를 적습니다.
