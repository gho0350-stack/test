# 위례 학군지도 (가칭) — 초안 v0.1

> 위례신도시(북위례/남위례)를 영역별로 나눠 학군·교통·아파트 정보를 지도 UI로 보여주고,
> 인증 학부모 커뮤니티 + 유료 쪽지(카카오페이 결제) + 광고로 수익화하는 서비스의 초안입니다.
>
> **원칙**: 확인되지 않은 수치·사실은 절대 단정하지 않습니다. 검증된 내용에는 출처를 달았고,
> 아직 못 채운 항목은 `[확인 필요]`로 남겨뒀습니다. 실제 서비스를 만들기 전에 이 문서의
> `[확인 필요]` 항목을 먼저 실제 원천 데이터로 채워야 합니다.

## 2. 지역 구분 — 북위례 / 남위례

위례신도시는 **단일 행정구역이 아니라 서울 송파구·경기 성남시 수정구·경기 하남시 3개
지자체에 걸쳐 있는 신도시**입니다. "북위례/남위례"는 법정 행정구역명이 아니라
**입주 시기와 옛 부지 이력에 따른 관용적 구분**입니다.

- **남위례**: 송파구 거여동·장지동, 성남시 수정구 창곡동, 하남시 학암동 일부. 2017년경 대부분 입주 완료.
- **북위례**: 하남시 위례동 일대(옛 육군특수전사령부 부지). 부대 이전이 늦어져 개발이 지연되었고, 아직 입주가 진행 중/예정인 구간이 남아 있음.
- 최근 하남시 위례 지역의 **서울 편입(메가서울) 논의**도 있어 향후 행정구역 표기가 바뀔 수 있음.

출처:
- [위례신도시 - 위키백과](https://ko.wikipedia.org/wiki/%EC%9C%84%EB%A1%80%EC%8B%A0%EB%8F%84%EC%8B%9C)
- [위례신도시 - 나무위키](https://namu.wiki/w/%EC%9C%84%EB%A1%80%EC%8B%A0%EB%8F%84%EC%8B%9C) *(위키 특성상 교차검증 필요)*
- [같은 위례인데, 우리집만 떨어져…송파구로 묶여 토허제 악재 - 한국경제](https://www.hankyung.com/article/202503243148i)

⚠️ **정확한 법정동 경계(폴리곤)는 위 자료만으론 지도에 그릴 수 없습니다.** 실제 서비스용 경계 데이터는

## 3. 영역별로 보여줄 데이터 항목 — 항목별 출처 초안

### 3-1. 학교 정보 (초품아 / 배정 학교 / 자사고 여부)

- **1차 출처(공식)**: 학교알리미 — https://www.schoolinfo.go.kr/
  - 학생 수, 교원 수, 설립유형(공립/사립), 특성화 여부, **졸업생 진학 현황**(4년제/전문대/해외대학 진학자 수·비율, 취업 등 15개 공시 항목)을 학교별로 조회 가능.
  - 예: [위례한빛고등학교 공시 페이지](https://www.schoolinfo.go.kr/ei/ss/Pneiss_b01_s0.do?SHL_IDF_CD=0b715b78-cbda-4d57-ad77-40f60fa1a262) — 성남시 수정구 창곡동, 공립 일반고, 2016.3 개교, 고교학점제 연구학교(자사고 아님).
- **초등학교 배정(초품아 여부)**: 단지별 배정 초등학교는 **경기도교육청/성남·하남 교육지원청 학교군 배정 고시**를 단지 주소 기준으로 대조해야 확정됩니다. → `[확인 필요]`
- **자사고/특목고 지정 현황**: 교육부·시도교육청 고시 목록 대조 필요. 현재 확인된 바로는 위례권 고교 중 확인된 자사고는 없고(위례한빛고는 공립 일반고), 위례권 내 자사고 유무 자체를 `[확인 필요]`로 둡니다.

### 3-2. "SKY·의대 보낸 명수" — ⚠️ 가장 리스크가 큰 항목

이 항목은 **공식 공시 데이터가 존재하지 않는 경우가 대부분**입니다.
- 학교알리미가 공시하는 건 "4년제 대학 진학률/진학자 수" 수준이며, **특정 대학명(서울대 등)이나 의대 합격자 수를 학교가 의무적으로 공시하지는 않습니다.**
- 시중에 도는 "OO고 서울대 몇 명, 의대 몇 명" 수치는 대개 ①졸업생/학부모 커뮤니티의 자체 집계, ②종로학원·진학사 등 사설 입시업체의 추정 자료, ③학교가 자체 홍보용으로 배포한 보도자료 등에서 나오며, **표본과 집계 기준이 제각각이라 신뢰도 편차가 큽니다.**
- 소수 인원(예: "의대 3명")까지 밝히면 **졸업연도+학교+성적**의 조합으로 특정 학생이 역추적될 수 있어 개인정보/명예훼손 리스크가 있습니다.

→ 초안 단계 권고: 이 항목은 서비스에 넣더라도 **"OO고 자체 공개 자료 기준(연도), 출처: [링크]"** 식으로 반드시 1차 출처를 병기하고, 출처 불명 수치는 아예 넣지 않는 것을 권합니다. (아래 8장 "이견" 참고)

### 3-3. 사립/자사고 여부

교육부 고시 + 시도교육청 발표 자료 기준으로만 표기. 정권에 따라 자사고 정책(일괄 전환 시도 등)이 바뀌어 온 이력이 있어 **연 1회 이상 갱신 필요**. → `[확인 필요]` (지금은 위례권 고교 목록 자체를 재확인해야 함)

### 3-4. 대장아파트 / 실거래가

- **실거래가(공식·1차 출처)**:
  - 국토교통부 실거래가 공개시스템: https://rt.molit.go.kr/
  - 공공데이터포털 API — 아파트 매매: https://www.data.go.kr/data/15126469/openapi.do / 전월세: https://www.data.go.kr/data/15126474/openapi.do
  - 법정동코드 5자리 + 계약년월로 조회하는 구조라, 단지-법정동 매핑표를 미리 만들어야 함.
- **단지 정보(세대수, 입주연차, 평형 등) 참고용**: KB부동산(https://www.kbland.kr), 호갱노노(https://hogangnono.com), 리치고(https://richgo.ai) — 단, 이들은 2차 가공 데이터라 **정식 서비스에 그대로 긁어 쓰면 저작권/이용약관 위반 소지**가 있음. 실거래가 "숫자"는 국토부 원본에서 직접 받고, 이런 사이트는 참고·링크 용도로만 사용 권장.
- **"대장아파트" 지정**: 공식 기준이 없는 **커뮤니티 통념**입니다(8장 참고). 서비스에서는 "대장"이라고 단정하기보다 **"평당가 1위(YYYY년 M월 기준, 출처: 국토부 실거래가)"** 처럼 산출식을 명시하는 방식을 권장.

## 4. 화면 구성 (목업 기준)

1. **개념도(지도) 영역**: 북위례/남위례(송파·성남·하남 권역) 4개 구획을 스키매틱하게 표시. *실제 축척 아님* 명시.
2. **필터 칩**: 초품아 / 자사고·특목고 / 학군 우수(출처 표기 조건부) / 교통호재 / 대장아파트
3. **상세 패널**: 영역 클릭 시 학교·아파트·교통·실거래가 카드. 각 카드 우측 상단에 출처 링크 아이콘.
4. **커뮤니티 미리보기**: 게시판, "인증 학부모" 배지, "쪽지 보내기(유료)" 버튼 → 실제 결제는 미연동, 플로우만 표시.
5. **광고 슬롯**: 상단 배너 1, 리스트 중간 네이티브 광고 1 — 실 서비스 시 "광고" 표기 의무(6장 참고).

## 6. 법적으로 반드시 짚어야 할 것 (사업화 전 검토 필요 — 법률 자문 대체 아님)

1. **전자상거래법 — 통신판매업 신고**: 쪽지 이용권처럼 유상 재화(디지털 이용권)를 직접 판매하면 통신판매업자에 해당 → 사업자등록 + 관할 시/군/구 통신판매업 신고(정부24) 필요. 광고만 붙이는 것과 "결제를 받는 것"은 법적 의무 수준이 다름.
2. **전자상거래법 — 청약철회/환불**: 디지털 이용권(쪽지권)은 "사용 즉시 소비되는 재화"로 청약철회 제한 조항을 어떻게 설계할지 약관에 명시해야 함. 결제 전 고지 필수.
3. **카카오페이 가맹점 심사**: PG 표준약관, 정산주기, 환불정책 등 심사 통과 필요 (https://biz.kakaopay.com/applications).
4. **공인중개사법 — 중개 행위 금지선**: "정보 제공/매칭"을 넘어 특정 매물의 거래를 알선·중개하는 형태(예: 쪽지로 매물 정보 거래를 성사시키는 구조)로 가면 무자격 중개로 처벌 대상(공인중개사법 제48조)이 될 수 있음. **정보/커뮤니티 플랫폼**으로 포지셔닝을 명확히 유지해야 함.
5. **개인정보보호법**: "인증 학부모" 인증(실명·거주지·자녀 재학 확인 등) 절차를 두려면 개인정보처리방침, 본인확인 수단(휴대폰 본인인증 등 별도 계약), 민감정보(자녀 학교·성적 관련 정보는 준민감정보로 취급) 처리 근거 필요.
6. **표시광고법 / 공정위 추천·보증 심사지침**: 광고 콘텐츠와 정보 콘텐츠(예: "이 아파트가 대장" 같은 서술)를 명확히 구분·표기해야 함. 인스타 광고 집행 시에도 협찬/광고 표기 규정 적용.

## 8. 의견이 갈리는 지점 (그대로 서비스에 반영하면 안 되는 것들)

1. **"북위례/남위례" 경계 자체가 비공식**이라, 부동산 카페·중개사마다 어디까지 위례로 부르는지 다릅니다. 특정 단지를 임의로 어느 권역에 넣으면 "우리 단지는 왜 저기 껴 있냐"는 민원이 실제로 나옵니다(한국경제 기사 사례처럼 "위례인데 송파로 묶여 토허제 적용" 갈등도 있음).
2. **"대장아파트"는 순전히 여론/시세 스냅샷**이라 시점에 따라 바뀝니다. 특정 단지를 못박아 "대장"이라 라벨링하면 다른 단지 커뮤니티와 마찰이 생기고, 나중에 시세 역전 시 신뢰도 이슈로 번집니다. → 산출 기준·기준일을 항상 노출.
3. **자사고 존폐는 정치적으로 계속 흔들려 온 사안**입니다(일괄 전환 시도 → 법원 제동 → 유지, 정권 교체마다 재논쟁). "자사고 O/X"를 고정값처럼 박아두면 금방 틀린 정보가 됩니다.
4. **교통 호재는 위례의 오래된 갈등 소재**입니다. 위례신사선·위례과천선 모두 계획 변경·지연·구간 제외 논란이 반복돼 왔고, 이를 "호재"로만 마케팅하면 과장광고 논란 및 실거주자 불신을 살 수 있습니다.
5. **"SKY·의대 명수" 데이터의 출처 신뢰성 자체가 논쟁적**입니다(3-2 참고). 이 데이터를 그대로 노출하는 경쟁 서비스도 있지만, 정확도 논란과 개인정보 리스크를 안고 가는 구조라는 점은 사업 리스크로 명확히 인지하고 시작해야 합니다.
