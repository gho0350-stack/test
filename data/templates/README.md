# 수집 양식 (Claude가 못 가져오는 데이터용)

이 세션 환경은 학교알리미·국토부 실거래가·공공데이터포털·code.go.kr·네이버·호갱노노·아실·KB부동산
등 **외부 사이트에 직접 접속이 전부 막혀 있습니다** (egress 프록시 차단, Naver만이 아니라 전체).
검색(WebSearch)으로 뉴스·개요 정도는 계속 찾을 수 있지만, 표/원문 데이터를 긁어오는 건 불가능합니다.

그래서 아래 5종은 **사람이 직접 사이트에서 조회/다운로드해서 CSV로 채운 뒤 전달**하는 방식으로
진행합니다. 채워서 주시면 `data/wirye-data.js`, `data/regions.js`에 반영하겠습니다.

## 1. `transactions_template.csv` — 실거래가

- **어디서**: [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/) 화면에서 지역/기간 선택 후
  "다운로드"로 CSV/엑셀 직접 추출 (로그인 불필요). 또는 [공공데이터포털](https://www.data.go.kr/data/15126469/openapi.do)에서
  본인 명의로 API 키 발급 후 호출.
- **필수 컬럼**: `legal_dong`, `complex_name`, `dedicated_area_m2`, `contract_yyyymm`, `price_10k_won`
- `deal_type`: 매매/전세/월세 구분 (전월세 자료는 별도 API)
- 원본 파일을 통째로 줘도 되고, 이 양식으로 맞춰서 줘도 됩니다 — 컬럼명만 비슷하면 제가 변환합니다.

## 2. `schools_template.csv` — 학교 공시 정보

- **어디서**: [학교알리미](https://www.schoolinfo.go.kr/) 에서 학교명 검색 → "학생현황", "졸업생의 진로 현황" 탭
- **필수 컬럼**: `school_name`, `level`(초/중/고), `type`(공립/사립/자사고/특목고/일반고 등)
- `grad_4yr_univ_count`/`pct`: 있으면 채우고, **특정 대학명(서울대/의대) 진학 인원은 학교알리미에
  없는 경우가 대부분**이니 억지로 채우지 말고 비워두세요. 다른 출처(학교 자체 보도자료 등)에서만
  있으면 6번 항목처럼 별도로 출처를 달아 주세요.

## 3. `school_assignment_template.csv` — 단지별 배정 학교 (초품아 확정용)

- **어디서**: 성남교육지원청 / 하남교육지원청 / 서울시교육청(송파) 홈페이지의 "학교군 배정" 고시,
  또는 해당 교육지원청에 전화 문의가 제일 정확함. 네이버 부동산 단지 페이지의 "학교" 탭은
  참고만 하고 **반드시 교육청 고시로 재확인**.
- **필수 컬럼**: `complex_name`, `legal_dong`, `assigned_elementary`

## 4. `legal_dong_codes_template.csv` — 법정동코드 10자리

- **어디서**: [행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do) 검색 또는
  전체다운로드. 시/군/구 5자리는 이미 채워뒀고(`data/geo/sigungu.geojson` 대조), **동 5자리만
  채우면** 실거래가 API 호출에 필요한 10자리 코드가 완성됩니다.

## 5. `flagship_opinions_template.csv` — 블로그/카페발 "대장아파트" 여론

- 부동산 스터디 카페, pala07 블로그 등에서 본 주장을 옮길 때 쓰는 양식입니다.
- **주의**: 이 파일의 내용은 절대 그 자체로 "사실"로 표시하면 안 됩니다. 앱에 노출할 때도
  "커뮤니티 의견(출처: OOO, 날짜)"라고 명시하고, 실제 "대장아파트" 라벨은 1번 실거래가 데이터로
  계산한 값만 씁니다. (README.md 8장 참고)
- `note`에 항상 "미검증 여론"이라고 남겨두는 걸 기본값으로 해뒀습니다.
- 블로그/카페 글 URL과 함께 **본문에서 관련된 문장을 그대로 복사**해서 `claim`에 넣어주시면
  제가 과장/광고성 표현인지, 근거가 있는 주장인지 구분해서 정리해 드립니다.

## 이미 채울 필요 없는 것 (제가 계속 조사 가능)

- 교통 호재 진행 상황(위례신사선/위례과천선 등) — 뉴스 기사는 WebSearch로 계속 확인 가능
- 위례 개요, 행정구역 이력 등 일반 배경 정보 — 위키/뉴스 검색으로 커버 가능

이 둘은 제가 계속 갱신할 수 있으니 사람 손이 필요한 위 5종에 집중해 주시면 됩니다.
