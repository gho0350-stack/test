## 지표별 확보율 (3개교 × 2026학년도)
- 의대 단독: 휘문 O, 숙명 △(서울대 의대 3만), 세화 X(이미지)
- 의치한약수 합계: 휘문 O, 숙명 O, 세화 X
- 서울대 / 연세대 / 고려대: 휘문 O, 숙명 O, 세화 X → SKY 합계는 승인 후 합산
- 인서울 전체: 3개교 모두 X (기사에는 서강·성균관·한양·이화·중앙 등 일부 대학만 나옴)
- 2024·2025학년도: 이번에는 수집하지 않음(2025·2026 고교 선택 시리즈에서 같은 방식으로 추출 가능)

## 자동 추출 결과
- 텍스트 문장에 수치가 있는 2개교(휘문·숙명)는 근거 문구와 함께 13행이 추출됨(추출은 AI가 문장을 읽고 구조화). 이미지 표가 있는 1개교(세화)는 비전 추출이 필요.
- 집계 기준은 두 학교 모두 "합격건수, 중복 포함, 졸업생 포함"이라 서로 비교 가능하지만 **등록 인원이 아니다**.

## 기준이 불명확해 승인 전에 확인할 점
- 숙명여고 "메디컬 113"은 의약학 계열 합계이고 의대 단독 수치가 아님 → MEDGRP 로 저장.
- 숙명여고 같은 내용이 학교 탐방 기사(News/654268)에도 있음 → 같은 자료이므로 중복 집계 금지.
- 휘문고 SKY 합은 대학별 합격건수 합이라 중복합격이 이중으로 들어감.

## 입력하지 않은 값 (출처 미검증)
다른 곳에서 전달받은 값 중 원문으로 확인하지 못한 것은 입력하지 않았다: 휘문고 2024(의대 114)·2025(의대 152), 세화고 서울대 33·의대 75, 보인고·배재고·양정고 수치. (휘문고 2026 의대 139·서울대 50은 원문과 일치.)

## 출처별 이용 조건 (`data/admission_sources.csv`)
- 학교알리미: 공시 항목에 대학별 합격 실적 없음. 졸업생 수·진로 현황 대분류만.
- 지역내일: "저작권자 ©내일엘엠씨, 무단 전재 및 재배포 금지" → 수치·링크·짧은 근거 문구만 저장, 자동 대량 수집은 하지 않음.
- 베리타스알파: 약관 미확인 → 확인 전 자동 수집 금지.
- 리치고: 경쟁 서비스 DB 복제 금지, 사람이 교차검증용으로만 열람.

## 자동화에 필요한 것
1. 검색 단계: 네이버 검색 API 키(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`). 현재 환경에서는 검색 결과를 제가 직접 읽어 후보를 만드는 반자동만 가능.
2. 추출 단계: 비정형 문장·이미지 표를 구조화하려면 AI API 키(예: `ANTHROPIC_API_KEY`)가 Actions 에 필요. 키가 없으면 지금처럼 세션에서 사람이 요청해 추출.
3. 승인 단계: `data/admissions_review.csv` 의 decision 칸에 승인/반려 → `python3 pipeline/admissions_build.py --apply`.

## 2차 점검에서 바로잡은 것 (정합성)
- 휘문고 213은 **의치한약 소계(MED4)** 로 저장. 구성 합(139+16+12+12... 아닌 139+16+12+46)은 일치하지만 수의대가 원문에 없으므로 의치한약수 합계(MEDGRP)로 쓰지 않는다. 수의대를 포함해 220이라는 별도 수치는 원문 미확인이라 입력하지 않았다.
- 숙명여고 서울대 의대 3은 **서울대 한 대학의 의대**(SNU_MED)이며 전국 의대(MED)는 결측으로 유지.
- 숙명여고 '전체 의약학 계열 113'은 원문 범주 그대로(MEDSCI_RAW), 포함 학과가 불명확해 최종 지표에 반영하지 않음.
- 연세대·고려대는 원문이 캠퍼스(미래·세종) 포함 여부를 밝히지 않아 range_check=불명확. 서비스의 SKY 기준(서울 캠퍼스)과 같은지 확인되기 전에는 SKY 합산에 쓰지 않는다. 범위가 불명확한 행은 승인해도 최종 지표에 반영되지 않는다.
- 승인해도 반영되는 값(범위 확인): 휘문고 의대 139, 서울대 50 / 숙명여고 서울대 16.

## 3차: 학교 공식 홈페이지 자동 수집 결과 (2026-11-26, collect-admissions #3)
- 대상: 값이 없던 8개교 + 일부만 있던 3개교(총 11곳). 로봇 배제 표준(robots.txt)·1초 간격 준수.
- 결과: 추출된 실적 0행. 탐색은 정상 동작했다(학교당 6~22페이지 열람, 보인고는 robots.txt 가 막아 건너뜀).
- 원인 확인: 서울 표준 학교 홈페이지의 진로진학자료실 등 게시판이 대부분 비어 있거나(예: 잠실고 진로진학자료실 "총 0건") 대입 실적을 이미지·HWP 첨부로만 올려 텍스트 추출이 안 된다. 즉 크롤러 문제가 아니라 **공개된 텍스트 자료 자체가 없는 경우**가 대부분이다.
- 해석: 나머지 8개교(잠실·보인·배재·한영·진명·양정·서라벌·청원)는 현재 공개 출처로 대학별 합격 실적을 확보할 수 없어 화면에 "샘플" 표시로 남는다. 이후 학교가 자료를 올리거나 다른 공식 출처(학교알리미 졸업생 진로 현황 등)가 연결되면 채운다.
