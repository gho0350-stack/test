## 3. 위험 요소 (우선 확인)

1. **취소 거래 포함** (수정함): 1~2차 수집 가격에 해제 거래가 섞였을 수 있다. 다음 실행 결과로 `quality.cancelled` 건수를 확인한다.
2. **공개 저장소에 카카오 장소 데이터 저장**: 현재 저장소는 공개이고 카카오 로컬 API 결과(장소명, 좌표)가 커밋된다. 장기 저장·재제공 허용 여부는 이용약관 확인 전이다. 서비스 전에 약관 확인, 저장소 비공개 전환, 또는 카카오 결과를 저장하지 않는 구조 중 하나로 정리해야 한다.
3. 가격 범위 왜곡: 학교 목록의 최저~최고는 단지별 중앙값 기준으로 바꾸는 편이 안전 (현재는 단지 중앙값의 최저~최고로 이미 계산되며, 지도·상세 기준과의 분리는 미완).
4. 샘플 단지 수가 적어 "아파트를 빠짐없이 보여준다"는 MVP 기준 미충족.

## 6. 이번에 추가한 안전장치 (수집 신뢰성)

- API 일부 실패 시 기존 정상 데이터를 빈 값으로 덮어쓰지 않음 (연결 단지 수가 80% 미만으로 급감하면 이전 결과 유지, K-apt 누락분은 이전 값 유지 + `stale` 표시)
- 결과 파일에 인증키 문자열이 있으면 저장 중단
- 수집 품질 리포트 (`out/quality_report.md`, GitHub Actions 요약에도 출력): 연결률·좌표 변환률·취소 건수·API 응답 상태
- 단계별 독립 실행: 한 단계가 실패해도 나머지는 계속 진행
- 무거운 마스터 구축은 수동 실행(`master=true`) 때만, 단지 기본정보·좌표는 캐시해 재조회하지 않음
